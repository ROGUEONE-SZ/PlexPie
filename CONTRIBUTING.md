# Contributing to PlexPie

Thanks for wanting to help. PlexPie is a hobby project I built for my own home gym, so the best
contributions are small, focused and tested on a real Pi.

## Before you start

- **Questions and ideas:** start in [Discussions](https://github.com/ROGUEONE-SZ/PlexPie/discussions).
- **Bugs:** open an issue with the diagnostics report (the form asks for it).
- **Bigger changes:** open a discussion first, so we agree on the approach before you spend time on it.

## Pull requests

- One fix or feature per pull request, with a short description of what changed and why.
- Say what you tested it on (Pi model, screen, DAC) and how.
- Keep the style: plain Python 3 and bash, no new frameworks, readable over clever. Comments explain *why*.
- Anything people see (Settings, guides, README) is written in plain English for non-technical builders.
- Never commit secrets: no tokens, passwords, addresses or anything from your own `plexpie.conf`.
- It's fine to use AI tools (I do, see the README), as long as you understand, run and test what you submit.
